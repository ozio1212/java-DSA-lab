# DSA Laboratories

A repository containing solutions for laboratory tasks from the **Data Structures and Algorithms** course at Wrocław University of Science and Technology (Politechnika Wrocławska).

## General Information
- **Language:** Java
- **Structure:** Each package (`dsaa.labXX`) corresponds to subsequent laboratory sessions.

## Laboratory List

| Package | Topic | Brief Description |
| :--- | :--- | :--- |
| `dsaa.lab01` | Introduction | Java basics, I/O, drawing geometric shapes (pyramid, Christmas tree), and loading documents. |
| `dsaa.lab02` | Singly Linked Lists | Implementation of a custom singly linked list (`OneWayLinkedList`) based on the `IList` interface. |
| `dsaa.lab03` | Doubly Linked Lists | Implementation of a doubly linked list with head and tail references (`TwoWayUnorderedListWithHeadAndTail`). |
| `dsaa.lab04` | Cycled Doubly Linked Lists | Implementation of a doubly linked cycled list with a sentinel (`TwoWayCycledOrderedListWithSentinel`). |
| `dsaa.lab05` | Simple Sorting | Implementation of basic sorting algorithms: Bubble Sort, Insertion Sort, and Selection Sort. |
| `dsaa.lab06` | Advanced Sorting | Implementation of more efficient sorting algorithms: Iterative Merge Sort and Radix Sort. |
| `dsaa.lab07` | Hash Tables | Implementation of a hash table using open addressing with linear probing to handle collisions. |
| `dsaa.lab08` | Binary Search Trees | Implementation of a Binary Search Tree (BST) for efficient data storage and retrieval. |
| `dsaa.lab09` | Disjoint Sets | Implementation of the Disjoint Set (Union-Find) data structure using linked lists and forest representation. |
| `dsaa.lab10` | Graph Basics | Representation of graphs using adjacency matrices and implementation of BFS and DFS traversal algorithms. |
| `dsaa.lab11` | Graph Algorithms | Implementation of Dijkstra's algorithm for finding the shortest path in weighted graphs. |
| `dsaa.lab12` | String Matching | Implementation of Knuth-Morris-Pratt (KMP) and Finite Automaton algorithms for pattern matching. |
| `dsaa.lab13` | Computational Geometry | Implementation of the Graham scan algorithm for finding the Convex Hull of a set of points. |
